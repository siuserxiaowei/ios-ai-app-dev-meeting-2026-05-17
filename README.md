# iOS AI App 开发分享会议纪要专题站

内部完整版会议复盘站，基于 2026-05-17「iOS APP开发及推广经验分享」飞书智能纪要、文字记录、妙记 AI 产物和逐字稿整理。

## 内容结构

- `docs/index.html`：总览、核心结论、会议地图、适合谁读。
- `docs/workflow.html`：从 idea 到 PRD、AI coding、Xcode 测试、TestFlight、App Store 上架。
- `docs/business.html`：案例、成本、订阅/买断、定价、本地化与收款。
- `docs/growth.html`：社群、小红书、X、Reddit、ASO、兑换码与推广节奏。
- `docs/qa-risks.html`：Q&A、安卓/小程序判断、中转站、模型反复报错、合规边界。
- `docs/timeline.html`：按时间戳组织的章节复盘，链接回飞书妙记对应时间点。
- `docs/appendix.html`：工具清单、行动清单、术语表、来源说明。
- `sources/`：飞书拉取结果、逐字稿和整理校对记录，不作为 Pages 发布目录。
